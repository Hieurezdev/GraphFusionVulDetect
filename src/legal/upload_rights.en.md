# Right to upload the code

By uploading source code to ScanGuard, the user confirms that:

1. The code is theirs or their organisation's, or its owner has allowed them to have it analysed.
2. Uploading it breaks no confidentiality agreement, employment contract or third-party intellectual property right.
3. The code contains no secret keys, passwords or other people's personal data. If it does, the user is responsible for it and should remove them before uploading.
